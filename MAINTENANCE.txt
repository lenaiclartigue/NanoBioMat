NanoBioMat V3.17 — Actualités et référencement

Publier une actualité
1. Modifier news-data.json : copier un objet existant, puis attribuer un id et un slug uniques.
2. Renseigner date, catégorie et contenus en anglais/français. Conserver une date YYYY-MM si le jour exact n’est pas connu.
3. Catégories : group, projects, publications, resources, science.
4. Les images et liens dans la version française sont relatifs au dossier fr/ ; employer ../ pour les images partagées.
5. Exécuter : python3 tools/build_news.py
6. Déposer tous les fichiers modifiés/générés sur GitHub Pages.

Le script reconstruit les actualités, leurs pages individuelles, les deux flux feed.xml, le sitemap et les métadonnées.
Le fil conserve les ancres historiques news.html#magnetima, #photonano, #she et #patent.
Les mois sans jour exact ne sont pas transformés en dates artificielles dans le RSS.

Après publication
Ajouter la propriété https://lenaiclartigue.github.io/NanoBioMat/ dans Google Search Console et suivre les instructions de vérification du compte.
Soumettre https://lenaiclartigue.github.io/NanoBioMat/sitemap.xml et demander l’indexation de la page d’accueil.
Cette opération nécessite l’accès du propriétaire à Search Console ; aucun compte n’a été configuré automatiquement.

Flux RSS

Français : https://lenaiclartigue.github.io/NanoBioMat/fr/feed.xml

Les fichiers robots.txt ne peuvent piloter l’exploration que depuis la racine de l’hôte GitHub Pages. Aucun robots.txt inopérant n’a été ajouté dans le sous-dossier NanoBioMat.
