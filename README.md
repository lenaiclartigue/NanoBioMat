# NanoBioMat

Site de recherche de l’équipe NanoBioMat : nanoparticules magnétiques, nanoassemblages et interfaces biologiques.

- Site : https://lenaiclartigue.github.io/NanoBioMat/
- Français : https://lenaiclartigue.github.io/NanoBioMat/fr/
- Version : V4.36 — 27 octobre 2026.

## Structure technique

Site statique HTML, CSS et JavaScript, publié avec GitHub Pages. Les pages françaises se trouvent dans `fr/`. Les modules théoriques sont accessibles dans `theory-preview/index.html`. Les grandeurs et leurs sources figurent dans les modules concernés.

Conserver les chemins relatifs et la casse des noms de fichiers. Aucun serveur de calcul ni service privé n’est inclus dans ce site statique.
